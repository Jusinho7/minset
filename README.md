# 🛒 Site Vitrine E-Commerce — Alimentation

> Projet scolaire — Site vitrine d'une boutique alimentaire en ligne

---

## 📋 Description

Ce projet est un site vitrine de e-commerce dédié à la vente de produits alimentaires. Il permet aux visiteurs de consulter un catalogue de produits, de découvrir les offres disponibles et d'obtenir des informations sur la boutique.

Le site a été réalisé dans le cadre d'un projet scolaire individuel, sans framework ni bibliothèque externe — uniquement avec les technologies web fondamentales.

---

## 🛠️ Technologies utilisées

| Technologie | Rôle |
|---|---|
| **HTML5** | Structure et contenu des pages |
| **CSS3** | Mise en forme, responsive design |
| **JavaScript** | Interactions et logique côté client |
| **AJAX** | Chargement dynamique des produits sans rechargement de page |

---

## ✨ Fonctionnalités

- 📦 **Catalogue de produits** — affichage dynamique des produits alimentaires via AJAX
- 🔍 Consultation des fiches produits (nom, description, prix, image)
- 📱 Design responsive adapté mobile et desktop

---

## 📁 Structure du projet

```
projet-ecommerce/
├── index.html            # Page d'accueil
├── catalogue.html        # Page catalogue des produits
├── css/
│   ├── style.css         # Styles globaux
│   └── catalogue.css     # Styles spécifiques au catalogue
├── js/
│   ├── main.js           # Script principal
│   └── catalogue.js      # Chargement AJAX des produits
├── data/
│   └── produits.json     # Données des produits (JSON local)
└── assets/
    └── images/           # Images des produits et du site
```

---

## 🚀 Lancement du projet

Aucune installation requise. Il suffit d'ouvrir le projet dans un navigateur.

> ⚠️ Les requêtes AJAX nécessitent un serveur local pour fonctionner correctement (problème CORS avec `file://`).

### Option 1 — Extension VS Code

Installer **Live Server** dans VS Code, puis faire clic droit sur `index.html` → *Open with Live Server*.

### Option 2 — Python (serveur local rapide)

```bash
# Python 3
python -m http.server 8000
```

Puis ouvrir `http://localhost:8000` dans le navigateur.
